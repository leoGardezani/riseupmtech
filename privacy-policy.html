Política de Privacidade

Última atualização: 08 de setembro de 2026

A Rise Up MTech ("nós", "nosso" ou "empresa") está comprometida com a proteção da sua privacidade. Esta Política de Privacidade descreve como coletamos, usamos e protegemos suas informações ao usar nossos produtos e serviços, incluindo o Rise Up MTech ETL (Google Workspace Add-on), a Plataforma Rise Up MTech (aplicação web de automação de campanhas publicitárias, acessada por login) e o site riseupmtech.com.

Esta política cobre dois produtos distintos, com tratamentos de dados diferentes: (1) o add-on Rise Up MTech ETL, que integra dados de plataformas de mídia ao Google Sheets mediante autorização explícita do usuário; e (2) a Plataforma Rise Up MTech, aplicação web onde agências criam e gerenciam campanhas publicitárias com o apoio de inteligência artificial. Onde o tratamento difere entre os dois, isso é indicado explicitamente abaixo.

1. Informações que coletamos

No Rise Up MTech ETL (add-on):

  • Endereço de e-mail — para identificação do usuário e gerenciamento de licenças
  • Tokens de acesso às plataformas de mídia — armazenados localmente no Google Apps Script Properties Service (criptografado pelo Google), nunca transmitidos a servidores da Rise Up MTech sem necessidade
  • Dados de uso — número de extrações realizadas, plataformas utilizadas e período consultado, usados exclusivamente para gerenciamento de licenças e melhoria do produto
  • Dados de mídia extraídos — métricas das suas campanhas publicitárias. Esses dados são escritos diretamente na sua planilha Google Sheets e não são armazenados em servidores da Rise Up MTech

Na Plataforma Rise Up MTech (aplicação web):

  • Dados de conta e autenticação — nome, e-mail e foto de perfil obtidos via login social (Google OAuth)
  • Dados de workspace e campanha — nomes de campanha, público-alvo, orçamento, segmentações geográficas e demográficas, palavras-chave, e demais parâmetros que você insere pra criar e gerenciar campanhas publicitárias
  • Criativos publicitários — imagens, vídeos e textos que você envia (KVs de origem) ou que são gerados com apoio de inteligência artificial a partir do que você envia (ver seção 2 sobre uso de IA)
  • Tokens de acesso a plataformas de anúncio — Google Ads, Meta Ads e TikTok Ads, obtidos via OAuth ou fornecidos por você, usados pelo backend pra criar e gerenciar campanhas em seu nome
  • Métricas de uso do produto — páginas/abas acessadas dentro da plataforma, coletadas de forma agregada via Google Analytics (GA4) — ver seção 8

2. Uso de Inteligência Artificial

A Plataforma Rise Up MTech usa a API Gemini (Google) para gerar sugestões de conteúdo publicitário a partir dos dados que você fornece:

  • Geração de criativos — a partir de uma imagem de referência (KV) e instruções de texto que você fornece, a IA gera variações de imagem/vídeo em diferentes formatos, e headlines/descriptions para anúncios de texto (Google Ads Search)
  • Sugestão de públicos-alvo — a IA sugere segmentações de público (interesses, palavras-chave, dados demográficos) com base no briefing da campanha

O conteúdo enviado a essas gerações (imagens de referência, instruções, briefing de campanha) é processado pela API Gemini do Google exclusivamente para gerar a resposta solicitada. Todo conteúdo gerado por IA é uma sugestão — passa por uma etapa de revisão e aprovação humana antes de ser publicado em qualquer plataforma de anúncio (Google Ads, Meta Ads, TikTok Ads).

3. Como usamos suas informações

Usamos suas informações exclusivamente para:

  • Autenticar sua identidade e verificar sua licença ativa
  • Executar as extrações de dados das plataformas autorizadas por você (add-on) e a criação/gestão de campanhas em seu nome (Plataforma)
  • Escrever os dados extraídos na sua planilha Google Sheets (add-on)
  • Gerar sugestões de criativos e públicos-alvo via IA, mediante sua solicitação (Plataforma)
  • Enviar comunicações relacionadas ao serviço (renovação de licença, atualizações)
  • Entender como a Plataforma é usada, de forma agregada, pra melhorar o produto (GA4 — ver seção 9)
  • Melhorar a qualidade e confiabilidade do produto

Não vendemos, alugamos ou compartilhamos suas informações pessoais com terceiros para fins de marketing.

4. Acesso a dados de terceiros

Solicitamos acesso às APIs das seguintes plataformas mediante autorização explícita do usuário:

  • Google Ads (https://www.googleapis.com/auth/adwords)
  • YouTube Analytics (https://www.googleapis.com/auth/youtube.readonly)
  • Google Analytics / GA4 (https://www.googleapis.com/auth/analytics.readonly)
  • Google Sheets e Google Drive (https://www.googleapis.com/auth/spreadsheets, drive.readonly, drive.file)
  • Meta Ads API — mediante token fornecido pelo usuário ou OAuth
  • TikTok Ads API — mediante token fornecido pelo usuário
  • LinkedIn Ads API — mediante token fornecido pelo usuário
  • Pinterest Ads API — mediante token fornecido pelo usuário

No add-on, o acesso é utilizado exclusivamente para leitura de dados de desempenho de campanhas e escrita na planilha do usuário — nenhuma operação de criação, modificação ou exclusão de campanhas é feita pelo add-on. Na Plataforma, esse acesso é utilizado pra criar, configurar e gerenciar campanhas publicitárias diretamente nas plataformas listadas, sempre a partir de uma ação explícita sua.

Uso limitado: O uso de dados obtidos via APIs do Google se restringe ao propósito declarado de cada produto e está em conformidade com a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Armazenamento e segurança

Add-on:

  • Tokens de acesso a plataformas de terceiros (Meta, TikTok, LinkedIn, Pinterest) são armazenados no Google Apps Script Properties Service, criptografado e gerenciado pelo Google
  • Dados de campanhas extraídos são escritos diretamente na planilha do usuário e não passam por servidores da Rise Up MTech

Plataforma:

  • Backend hospedado no Google Cloud Run (região southamerica-east1), acessado via HTTPS
  • Dados de workspace/campanha/audiência são armazenados no Firestore e no BigQuery (ambos Google Cloud, região southamerica-east1), segmentados por cliente
  • Criativos (imagens, vídeos) são armazenados no Google Cloud Storage, com acesso controlado por URLs assinadas de tempo limitado
  • Tokens de acesso a plataformas de anúncio são armazenados de forma segura no backend (Google Secret Manager / Firestore), nunca expostos no frontend

6. Retenção de dados

Mantemos apenas os dados necessários para o funcionamento do serviço:

  • E-mail e status de licença/conta: pelo período da assinatura + 90 dias
  • Logs de uso: até 12 meses
  • Dados de campanha, criativos e públicos-alvo (Plataforma): mantidos enquanto o workspace estiver ativo, e por até 90 dias após o cancelamento, salvo obrigação legal de retenção maior
  • Tokens de plataformas: armazenados enquanto a conexão estiver ativa e removidos ao desconectar (add-on: ao desinstalar ou revogar acesso; Plataforma: na aba Conexões)

7. Seus direitos (LGPD)

Em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

  • Confirmar a existência de tratamento de seus dados pessoais
  • Acessar seus dados pessoais
  • Corrigir dados incompletos, inexatos ou desatualizados
  • Solicitar a anonimização, bloqueio ou eliminação de dados desnecessários
  • Revogar o consentimento a qualquer momento
  • Solicitar a exclusão completa dos seus dados

Para exercer esses direitos, entre em contato: privacidade@riseupmtech.com

8. Revogação de acesso

Você pode revogar o acesso a qualquer momento:

  • Para dados Google: acesse myaccount.google.com/permissions e remova "Rise Up MTech ETL" ou "Rise Up MTech"
  • Para tokens de plataformas (Meta, TikTok, LinkedIn, Pinterest): desinstale o add-on, ou remova os tokens na aba Conexões da Plataforma

9. Cookies e rastreamento

A Plataforma Rise Up MTech (aplicação web) usa Google Analytics 4 (GA4), via Google Tag Manager, para entender de forma agregada como o produto é usado — quais telas/funcionalidades são mais acessadas — e priorizar melhorias. Isso envolve cookies e identificadores de uso para associar eventos de navegação à mesma sessão/usuário, conforme as práticas padrão do GA4. Não usamos esses dados para publicidade direcionada a terceiros. Você pode saber mais sobre como o Google trata esses dados na Política de Privacidade do Google, e pode se opor ao rastreamento do Google Analytics instalando o complemento de desativação do Google Analytics no navegador.

O add-on Rise Up MTech ETL não coleta dados de navegação nem usa cookies — roda inteiramente dentro do ambiente do Google Sheets/Apps Script.

10. Alterações nesta política

Podemos atualizar esta Política de Privacidade periodicamente. Notificaremos usuários ativos por e-mail sobre mudanças significativas. O uso continuado do serviço após a notificação constitui aceitação da política atualizada.
